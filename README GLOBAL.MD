# NEXO – Stay Alert. Stay Protected.

Plateforme web de sensibilisation et de prévention contre le phishing.

## Objectif
Aider les utilisateurs à reconnaître, analyser et éviter les tentatives de phishing grâce à des outils interactifs et pédagogiques.

## Technologies
- Frontend : React
- Backend : Python / FastAPI
- Base de données : PostgreSQL
- Infrastructure : Docker / GitHub

## Équipe
Projet Ydays – Ynov Campus  
10 étudiants répartis en 5 groupes.
